# Argument Interrogation Checklist

Salvaged from the retired `/argument-governance` skill: the questions carry
the value; the 5-CSV standing ledger it prescribed was never maintained by
any project and is retired. Use this as a one-shot interrogation during
`/review` or before a major edit — emit a REPORT, not standing files.

When the question concerns a stronger headline, an extrapolation, or a
change in contribution emphasis, use
[`argument-licence/argument-level-lock.md`](argument-licence/argument-level-lock.md)
for the four-level distinction and six-line claim licence. Its
[schema and checks](argument-licence/README.md) are optional interpretation
references for existing records, not a new ledger requirement or an
enforcement mechanism.

## Gap → contribution → claim → evidence

1. Does every stated contribution answer a **named** gap, in the
   manuscript's own words? A contribution without a gap is a feature list.
2. State each core claim in one sentence. Can a hostile reader broaden it by
   deleting a qualifier? Then the qualifier is load-bearing — check it
   appears every time the claim does.
3. Does the evidence **type** match the claim type? A performance claim
   wants measurement; a generality claim wants coverage; a causal claim
   wants an intervention or an explicit causal-inference design. Citation
   volume never substitutes for type-match — over-citation usually hides a
   weak spine.
4. Which claims rest on sources marked `abstract_only`/`metadata_only` in
   the reading notes? Those are unproven by construction.

## Examiner-attack pre-mortem

For the three most load-bearing claims, write the strongest attack a
sceptical examiner would make (method, alternative explanation, scope,
missing literature), then rate the current defence: `solid` (answered in
text), `patchable` (answer exists, not yet in text), `exposed` (no answer).
`exposed` on a core claim is a blocker, not a note.

## Limitations

A limitations section that only lists flattering limitations is an attack
surface. Include the limitation the pre-mortem found hardest to defend.
