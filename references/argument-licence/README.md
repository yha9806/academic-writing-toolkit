# Argument licence references

This is the reference-document disposition offered in issue #39. The useful
claim-scope material is available to the existing `audit` and `review` skills
without adding a tenth catalogue entry or restoring the retired plugin mirror.

Start with [Argument level lock](argument-level-lock.md) when reviewing a
headline, contribution hierarchy or extrapolation. It distinguishes a broad
field gap, a paper contribution, an empirical finding and a broader claim,
then identifies whether the repair needs wording, argument design or new
evidence. Return a bounded report. Ordinary edits do not require this pass.

[Legacy schema](legacy-schema.md) and [legacy checks](legacy-checks.md) preserve
the meaning of existing records and rule IDs. They are not a maintained
runtime validation contract: the old branch's large validator and plugin
mirror were not transplanted. Existing author labels remain assertions for
review, not independently verified scientific evidence or approval events.
Do not require a new standing ledger to use the argument-level reference.
