# 研究方向与论文规划

`/research-plan` 是 AWT 的试用技能，帮助用户从模糊想法开始梳理研究价值、现实条件、证据需求和论文规划。它可以单独使用，也可以在研究中途根据新证据重新判断下一步。

## 开始使用

在能发现 AWT 技能的工作区中，用自然语言提出需求，或按宿主支持的方式指定 `research-plan`。例如在 Codex 中：

```text
使用 $research-plan。我想研究一个方向，目前只有这个想法：……
先帮我明确最值得调查的问题，不知道的信息可以保留。
```

```text
使用 $research-plan，结合这些材料生成一份研究讨论记录。
我现在是……阶段，可用时间……，已有条件……。
请分别写学位论文主线和单篇论文可能的贡献。
```

```text
使用 $research-plan 更新 planning/research-discussion.md。
新情况是……。比较哪些原判断仍成立、哪些需要调整，保留上一版和变化依据。
```

这是一项由 AI 宿主执行的技能，不是新增的 `awt` 终端子命令。仓库安装和工作区链接方式见[设置说明](../setup-codex-cli.md)。现有全局安装需要按该说明更新，才能获得新技能。

已有手稿时，可以先用 `/review` 审稿，再把审稿结果交给本技能讨论后续路径；审稿评价当前材料，本技能讨论未来，两者分开记录。

## 三种用法

| 用法 | 输入可以是什么 | 输出 |
|---|---|---|
| 讨论方向 | 一句想法、一个现象、理论疑问或实际困难 | 已知条件、关键未知、值得继续调查的问题和一个下一步；可以先在对话中讨论。 |
| 生成规划 | 研究目标、实际要求、条件，以及现有材料 | 一页研究讨论记录；学位论文主线与候选单篇论文贡献分开呈现。 |
| 重新评估 | 现有记录，加上新文献、数据、结果、条件或目标变化 | 原判断与新判断、变化依据和行动影响；继续、缩题、调整、暂停或停止由研究者决定。 |

讨论按已有信息推进，不要求把整张表一次填完，也不要求已有手稿、实验结果或明确期刊。缺少文献时留下需要查证的内容，不能把未检索当作“没有人做过”。

## 输出与保存

请求生成、整理、保存或更新研究规划时，默认写入研究项目的 `planning/research-discussion.md`；指定过文件或已有记录时沿用原位置。单纯询问一个方向时，可以只在对话中回答。

更新前先保留原文件的完整内容，使用已有版本历史或 `planning/history/` 下不会覆盖旧文件的带日期快照。新版本写明上一版位置和本次变化；如果无法保留旧版，先返回建议更新内容并保持原文件不变。

记录使用[随技能提供的模板](../../.claude/skills/research-plan/references/discussion-record.md)，覆盖研究问题、调查价值、最近已有工作、条件与未知、最小验证、两类论文规划、待确认事项。设想、研究者报告、已检查材料和实际结果就近区分。

贡献不限于新模型或解决方案；一项深入研究也可以形成主线，不默认“一章一篇”。学位和投稿要求需要核实，工具建议不能代替研究者决定。

## 试用状态

技能结构、发现和安装检查只能说明入口与资源可用。假设案例演练可以暴露行为问题，不能证明它已改善实际研究决策。需要用不同阶段的实际选题评估是否更早发现硬约束、补对证据、明确下一步，以及记录负担是否合理；见[方法与试用方案](../specs/2026-10-08-research-direction-and-paper-planning.md)。
