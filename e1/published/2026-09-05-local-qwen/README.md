# Local Qwen E1 pilot — 2026-09-05

The three-source paired experiment was collected with real model responses
through the published dsh launcher. It did **not demonstrate improved
academic-writing efficacy** under this local configuration. Neither arm
produced a notes file that passed the shipped lint on any of the three
sources. E2 author acceptance remains unexecuted.

Read the untouched producer [comparison table](results.md) and
[metrics JSON](metrics.json), then the machine-generated
[observation summary](analysis.md). The latter exposes missing files and
zero denominators that must not be interpreted as perfect accuracy.

## What ran

- Three public ACL papers, physical PDF pages 1-5 per source, fixed before
  generation; see the [protocol and disclosed collector amendments](../../protocols/2026-09-05-local-qwen.md).
- Local `qwen3-vl:4b-instruct` (4.4B, Q4_K_M) via Ollama 0.33.2, with the
  fixed alias/parameters in [Modelfile](Modelfile). No cloud model was tested.
- Published harness `@deepseek-ai/dsh@0.1.0-rc.6`.
- Twelve retained task observations: notes and draft in each of two arms
  for every source. Two output-budget exhaustions and one empty response
  remain in the skills arm. A separate read-only transport failure was
  explicitly retried once after a health check and is disclosed in provenance.
- Final producer revision: `a197d8738a154789f75836d96964e42e35bb4bb2`.
  Earlier observations were preserved rather than re-generated; their
  producer and log hashes are linked through `metrics.json.continuation`.
  Sources, model parameters and the four graders stayed fixed.

## Evidence and limitations

The [verification receipt](verification.json) binds the three input hashes,
eleven final implementation files, twelve unique session logs and the three
prior result directories. The metrics and table here are byte-identical
copies of the final producer outputs; [analysis.json](analysis.json) was
generated by `e1/summarize-run.py` from those outputs and logs.

No adjacent page citations or draft citations were detected by the existing
extractors. Thus page accuracy and the zero unopened-citation count do not
demonstrate correct referencing. No detected quotation passed the strict
returned-text matcher. PDF column order, hyphenation and quotation changes
can all affect that result; it is not a semantic-factuality judgement.

This is a convenience sample, one small local model, a fixed arm order and
no replication. The treatment combines persona, guards and skills, so it
does not isolate skill wording. There is no statistical significance claim,
no result for untested cloud routes and no author-use acceptance claim.

Before an efficacy claim, the next experiment should address notes-template
adherence, reliable file completion and citation/page-format coverage. Any
changed prompts, models or graders belong to a new, separately identified
comparison; these observations must remain visible.

## Reproduction

Copy [pdfs.json](pdfs.json) to `e1/pdfs.json` and obtain the three publisher
PDFs listed in the protocol under `e1/sources/`, verifying the recorded
SHA-256 values. The PDFs are not committed. Install the locked dependencies
as described in [the runner guide](../../README.md). With the base Qwen
model installed, create the dedicated alias and run:

```sh
ollama create awt-e1-qwen3vl4b-32k:20260905 -f e1/published/2026-09-05-local-qwen/Modelfile
node e1/run-e1.mjs --real --check --provider ollama --model awt-e1-qwen3vl4b-32k:20260905
node e1/run-e1.mjs --real --provider ollama --model awt-e1-qwen3vl4b-32k:20260905
```

Preflight is generation-free. A fresh execution is a new replication and
does not overwrite this packet. Raw session logs, original attempts and
their full source excerpts are preserved locally with the experiment
handoff; this directory publishes the compact measured record.
