# 投稿与毕业论文送审前校验

以下命令在仓库的 `workbench/` 目录运行；从仓库根目录安装请见[组件入口](../README.md)。

当前源码版的 Workbench 已增加统一的 **6. 投稿前校验**。可以直接在
分批任务旁点击 **投稿前校验（本地）**。已发布的 v0.5.0 安装包尚不包含
这项功能，需要从当前仓库安装：

```powershell
python -m pip install -e ".[documents]"
awt
```

本模块不调用模型、不访问指南链接，也不改变原文件。即使正文审阅使用旧版
模型或小模型，仍可使用全部本地校验；新增模型调用和 API 费用均为零。

## 使用流程

1. 在跨文件审阅页导入论文、参考文献和需要纳入报告的附件。
2. 填写目标期刊、会议或学校，记录指南来源、版本或日期，按实际要求配置。
3. 选择材料角色：正文参与计数和匿名扫描，参考文献参与引用匹配，附件只
   记录文件及哈希。不要把同一稿件的 PDF、DOCX 同时算作两份正文。
4. 填写长度、页数、图表、页面尺寸、大纲、声明和必需材料要求；无要求留空。
5. 暂停仍在进行的模型或排版任务，点击 **运行投稿前校验**。查看问题和
   原文定位，处理后按需要记录核对人、结论及依据。
6. 修复后导入同名修改稿并重新运行。下载完整 JSON 或阅读版 Markdown，
   交给作者核对最终材料。

校验未结束时可以取消。完成报告保存在本机，重启可恢复查看；中断的本地
扫描重新运行，不会重新调用模型。每个任务最多保留 20 份报告，每份最多
展开 2,000 项、每页 20 项。超过上限仍保留完整问题计数并提示缩小范围，
不会把省略项算作通过。

## 已接入的检查

| 范围 | 自动检查 | 明确保留的人工或未检查项 |
|---|---|---|
| 材料与规范 | 文件齐备、正文角色、TODO/占位符、本机路径、配置快照 | 最新指南和实际适用范围需作者确认 |
| 长度与页数 | 提取文字、摘要、所选 PDF 页数与上限对照 | 文字提取缺失不能通过；DOCX/文本页数需最终 PDF |
| 大纲与正文 | 必需标题归一化匹配，本章及已识别子节的关键词匹配 | 章节是否完成研究任务、论证充分性需逐项核对 |
| 图、表与正文 | 常见中英文图表号、重复/缺失/未引用图注、子图与主图配对、LaTeX label/ref | 图组数值、单位、样本、图例、结论、有效 DPI 和图像质量需核对 |
| 引用与文献 | BibTeX 字段、键重复、常见 DOI/URL/年份格式，cite 键和常见数字引用配对 | 来源真实性、撤稿、在线元数据与引用是否支持主张未自动验证 |
| 匿名与声明 | 正文身份关键词/邮箱、PDF/Word 作者属性、必需声明标识 | 图像身份、隐藏内容、致谢、自引、声明内容与作者认可需核对 |
| 最终文件 | PDF 页面尺寸、页面字体资源嵌入信息、常见 PDF 批注、Word 正文修订/批注标记 | 图形对象字体、复杂 Word 内容和实际视觉效果需核对 |
| 已有审阅 | 正文文字覆盖、计划内批次完成情况、已有模型意见 | 全部批次完成不证明所有关系已覆盖；意见仍由作者判断 |
| 排版记录 | 当前文件哈希、全稿页数覆盖、逐页渲染和人工记录 | 旧稿、局部页数和未确认页面不能算当前全稿通过 |

正文统计包含标题、图注和表格，排除已识别的参考文献。可选英文词加逐个
汉字，或非空白字符；这不一定等同于期刊或学校的最终计数口径。

大纲每行填写 `标题 | 本章任务 | 关键词1；关键词2`，也可以只写标题。
标题匹配支持大小写、空格和常见数字前缀归一化，不做自动语义同义改写。
提取或自动分章不准确时，应先核对原文和章节识别。关键词存在只表示找到
字面文字，不等于任务完成。多图的自动检查目前是编号和引用配对，联合图组
语义核验保留为人工项；原有可选视觉审阅仍是一张所选图像一次请求。

引用支持常见 LaTeX cite/nocite、数字方括号及部分英文姓氏—年份形式。
中文作者名、复杂多作者格式、公式中的方括号、引用范围及未导入的 TeX
include/input 文件都可能需要人工核对。BibTeX 宏不会执行，在线核验可以
另用已有的 verify-refs 工具。

## 报告状态和版本

| 状态 | 含义与处理 |
|---|---|
| 阻断问题 | 按已配置规则发现缺失或超限；修复材料或纠正规则后重查，不能直接人工勾掉 |
| 警告 | 发现可疑项，需修复或记录适用性判断 |
| 需人工核对 | 本地程序不能判断的内容，填写核对人与依据 |
| 尚未检查 | 材料、配置、依赖或覆盖不足，不能当作通过或直接改成已核对 |
| 规则检查通过 | 仅对应这一条本地规则与它明确限定的检查范围 |
| 已记录人工核对 | 有人工记录，可撤回；不等于所有作者批准或投稿系统验收 |

每份报告保存文件 SHA-256、规则快照、规则哈希和报告哈希。人工记录另存，
绑定该报告与该版本；JSON 导出还包含导出内容的哈希。稿件、规则、审阅要求、
模型记录或排版记录变化时，旧报告标为**已过期**，禁止用它记录当前稿件
的人工核对。历史报告仍可导出，会保留过期标记。报告哈希代表完整性绑定，
不是核对人的身份认证或电子签名。

排版对照中的“修改后副本”如果是本次提交稿，须作为同名修订导入正文，
才能与该副本的全稿逐页记录匹配。Markdown/TeX 源文档没有最终排版，选择
“要求排版核验”后会提示缺少可绑定的最终文件。

## 长论文与验证边界

沿用 [长论文输入边界](thesis-scale-review.md)：PDF 最多 1,000 页，
每份 80 MB、合计 160 MB，另外受文字和区域数量限制。本模块已用
200 页虚构 PDF 验证本地校验、页数统计、末章关键词和有界报告；它没有
把整篇论文发给模型。1,000 页是输入上限，200 页是当前实际规模测试，
不代表验证过每种真实学位论文版式。

扫描页无自动 OCR。缺少可选 PDF 依赖或存在无法提取的页面时，会明确
显示尚未检查。科学有效性、原创性、伦理审批、作者许可和真实平台验收
不能由本模块自动宣告完成。
